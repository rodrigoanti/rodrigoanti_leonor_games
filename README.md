# Pinta Leo 🎨

App de pintura para niños pequeños, optimizada para pantallas táctiles móviles.

## Requisitos

- Node.js >= 18

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Producción

```bash
npm run build
npm start
```

## Características

- Canvas a pantalla completa con trazos gruesos
- 8 colores grandes y fáciles de tocar
- Herramientas: pintar, borrar y limpiar (con confirmación de doble toque)
- Diseño mobile-first sin scroll ni zoom accidental
